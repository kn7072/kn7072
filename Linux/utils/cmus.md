# Горячие клавиши для cmus

Этот список содержит стандартные сочетания клавиш для музыкального плеера cmus. Большинство комбинаций работают во всех режимах (common context), если не указано иное

## Управление воспроизведением

| Клавиша | Действие                                        |
| ------- | ----------------------------------------------- |
| `x`     | Начать воспроизведение / воспроизвести с начала |
| `c`     | Пауза / возобновление воспроизведения           |
| `v`     | Остановить воспроизведение (сброс позиции)      |
| `b`     | Следующий трек                                  |
| `z`     | Предыдущий трек                                 |
| `B`     | Следующий альбом                                |
| `Z`     | Предыдущий альбом                               |

## Навигация по треку (перемотка)

| Клавиша     | Действие                     |
| ----------- | ---------------------------- |
| `.`         | Перемотка вперёд на 1 минуту |
| `,`         | Перемотка назад на 1 минуту  |
| `l` или `→` | Перемотка вперёд на 5 секунд |
| `h` или `←` | Перемотка назад на 5 секунд  |

## Регулировка громкости

| Клавиша     | Действие                        |
| ----------- | ------------------------------- |
| `+` или `=` | Увеличить громкость на 10%      |
| `-`         | Уменьшить громкость на 10%      |
| `]`         | Увеличить громкость (+0% / +1%) |
| `[`         | Увеличить громкость (+1% / +0%) |
| `}`         | Уменьшить громкость (-0% / -1%) |
| `{`         | Уменьшить громкость (-1% / -0%) |

## Режимы воспроизведения

| Клавиша       | Действие                                             |
| ------------- | ---------------------------------------------------- |
| `s`           | Переключить перемешивание (shuffle)                  |
| `r`           | Переключить повтор списка (repeat)                   |
| `Ctrl+R`      | Переключить повтор текущего трека (repeat current)   |
| `C` (Shift+c) | Переключить режим продолжения (continue)             |
| `m`           | Переключить режим AAA (Artist/Album/All)             |
| `t`           | Переключить отображение оставшегося времени          |
| `o`           | Переключить сортировку воспроизведения (play_sorted) |
| `M` (Shift+m) | Переключить режим библиотеки (play_library)          |
| `f`           | Переключить следование за текущим треком (follow)    |

## Переключение между режимами (видами)

| Клавиша | Вид                                                     |
| ------- | ------------------------------------------------------- |
| `1`     | Дерево исполнителей/альбомов (library)                  |
| `2`     | Вся библиотека (sorted)                                 |
| `3`     | Плейлист                                                |
| `4`     | Очередь воспроизведения (queue)                         |
| `5`     | Файловый менеджер (browser)                             |
| `6`     | Фильтры                                                 |
| `7`     | Настройки                                               |
| `Tab`   | Переключение между панелями (например, в режимах 1 и 3) |

## Быстрый способ: создать и наполнить плейлист

Этот метод позволяет создать плейлист и сразу добавить в него треки.

Создайте новый плейлист: Перейдите в командный режим (нажмите :) и введите команду:
`:pl-create Имя_моего_плейлиста`

- Нажмите Enter. Плейлист с таким именем будет создан
- Переключитесь в окно плейлистов: Нажмите клавишу 3, чтобы перейти в режим просмотра плейлистов
- Отметьте ваш плейлист: С помощью клавиш j/k выберите только что созданный плейлист и нажмите Space, чтобы отметить его
- Теперь все добавляемые треки будут попадать именно в него.

Добавьте треки: Есть два способа:

- Из библиотеки: Нажмите 2, чтобы перейти в режим "Вся библиотека". Найдите нужные треки (можно использовать поиск /), выделите их клавишей Space и нажмите y

- Из файловой системы: Нажмите 5 для перехода в файловый менеджер, найдите папку с музыкой и нажмите Space или Enter, чтобы войти в неё. Затем снова нажмите y

## 1. Добавление музыки в библиотеку cmus

Способ А: Добавить всю папку с музыкой (рекомендуется)

Если у вас есть папка, например ~/Music или ~/Downloads/MyMusic, где лежат все ваши mp3/flac файлы:

- Нажмите : (двоеточие) для входа в командный режим.

- Введите команду:
  `:add ~/Music` (Замените ~/Music на ваш реальный путь).

- Нажмите Enter.

Что произойдёт: cmus просканирует эту папку и все вложенные подпапки, найдёт все аудиофайлы и добавит их в библиотеку. Процесс может занять несколько секунд или минут, в зависимости от количества файлов.
Способ Б: Добавить через файловый менеджер (интерактивно)

Если вы не помните точный путь или хотите посмотреть структуру папок:

- Нажмите 5 — вы перейдете в режим файлового менеджера.

- Вы увидите список папок и файлов в текущей директории (обычно это ваша домашняя папка ~).

- Используйте клавиши j/k для навигации и Enter для входа в папки.

- Найдите папку с музыкой (например, Music или Downloads).

- Наведите курсор на нужную папку и нажмите Space (пробел) — папка будет выделена (отмечена).

- Нажмите a — все файлы из отмеченной папки будут добавлены в библиотеку и в текущий плейлист.

## 2. Добавление отдельных файлов или папок

Команда Действие
:add /путь/к/папке Добавить всю папку рекурсивно
:add /путь/к/файлу.mp3 Добавить один файл
:add ~/Music/\*.mp3 Добавить все mp3-файлы в папке (с помощью wildcard)

## 3. Что делать после добавления?

После того как вы выполнили :add, музыка появится в библиотеке. Теперь вы можете:

- Нажать 2 — увидеть все треки в виде плоского списка.

- Нажать 1 — увидеть дерево исполнителей и альбомов (если у файлов заполнены теги).

- Нажать 3 — увидеть плейлист, в который были добавлены файлы (по умолчанию они попадают в "default" плейлист).

#### 💡 Дополнительно: Как переключаться между списком плейлистов и треками

**Если вы оказались внутри плейлиста и хотите вернуться к общему списку плейлистов, обычно используется клавиша `Tab` или `Escape` для переключения между панелями (название плейлиста ↔ список треков)**

## 4. Как сделать, чтобы музыка запомнилась навсегда?

cmus автоматически сохраняет состояние библиотеки при выходе, если вы выходите через :q. Но если вы закрываете терминал "красным крестиком", изменения могут потеряться.

Чтобы сохранить библиотеку вручную:
`:save ~/.config/cmus/playlist.pls`

Чтобы при следующем запуске cmus автоматически загружал эту библиотеку, добавьте в файл ~/.config/cmus/autosave строку:

`set save_playlist=true`
`set save_library=true`

Или просто всегда выходите через :q — тогда всё сохранится само. 5. Быстрый пример: добавить музыку и создать плейлист для группы

Допустим, у вас есть папка ~/Music/rock/, внутри которой лежат папки Nirvana/, Metallica/, Radiohead/.

- Открываете cmus.
- :add ~/Music/rock/ — вся музыка добавляется в библиотеку.
- Нажимаете 1 (дерево) — видите список групп.
- Создаёте плейлист: :pl-create Nirvana_playlist.
- Нажимаете 3, выбираете Nirvana_playlist, нажимаете Space.
- Нажимаете 1, находите Nirvana, наводите курсор на название группы, нажимаете y.
- Готово! Все треки Nirvana скопированы в ваш плейлист.

📌 Важное замечание

cmus не копирует файлы — он только запоминает пути к ним. Если вы переместите или удалите файлы на диске, они исчезнут из библиотеки и плейлистов. Поэтому всегда добавляйте папки, которые не планируете перемещать в ближайшее время.

### 🎯 Основные параметры команды `:add`

По умолчанию, если вы просто введёте `:add /путь/к/папке`, музыка добавится в **текущий вид** (тот, в котором вы находитесь). Но с помощью флагов можно точно указать место назначения

| Параметр (флаг) | Назначение         | Что делает                                               |
| --------------- | ------------------ | -------------------------------------------------------- |
| `-l`            | **Library**        | Добавляет музыку в вашу основную медиатеку (виды 1 и 2). |
| `-p`            | **Playlist**       | Добавляет музыку в **отмеченный** плейлист (вид 3)       |
| `-q`            | **Queue**          | Добавляет треки в конец очереди воспроизведения (вид 4). |
| `-Q`            | **Queue (начало)** | Добавляет треки в начало очереди воспроизведения.        |

### 💡 Примеры использования

1. **Добавить в плейлист, не переключая виду**: Если вы находитесь в режиме 1 (дерево исполнителей), но хотите добавить папку в плейлист, просто введите:

   `:add -p ~/Music/MyNewAlbum`

   Музыка добавится в плейлист, который вы отметили пробелом в режиме 3.

2. **Добавить в библиотеку из любого места**: Находясь в режиме 4 (очередь), вы можете пополнить свою медиатеку:

   `:add -l ~/Downloads/SomeMusic`

3. **Игнорировать текущий вид**: Если вы просто введёте `:add ~/Music`, то музыка будет добавлена в то окно, в котором вы сейчас находитесь

### 📝 Резюме

Таким образом, для команды `:add` неважно, нажата ли у вас клавиша `1`, `2`, `3` или `4`.
Важно лишь то, с каким флагом (`-l`, `-p`, `-q`) вы её используете, чтобы направить треки в нужное место.

> почему при нажатии на кнопку b у меня происходит переход не на следующий трек а на какой-то другой. Какое-то странное поведение происходит переход к треку, который находится через несколько треков от текущего.

Вероятнее всего, это происходит из-за того, что у вас включен режим **перемешивания (shuffle)**. В этом режиме клавиша `b` переключает на "следующий" трек в соответствии со случайным порядком воспроизведения, а не с линейным списком

### 👀 Как проверить и исправить

Обратите внимание на правый нижний угол интерфейса `cmus`. Там отображаются индикаторы текущих режимов воспроизведения:

- **S** — Shuffle (перемешивание) **включен**.
- **R** — Repeat (повтор) **включен**.
- **C** — Continue (продолжение) **включен**

Если вы видите букву **S**, это объясняет вашу проблему.

**Что делать:**

- Чтобы **выключить** режим перемешивания, просто нажмите клавишу `s`

После этого клавиша `b` должна начать переключать треки строго по порядку в вашем плейлисте или библиотеке.

### 💡 Дополнительный нюанс: режим "AAA"

Есть еще одна настройка, которая влияет на порядок воспроизведения при включенном shuffle — это **режим AAA** (Artist/Album/All). Он переключается клавишей `m`

- **Artist**: Перемешивание происходит **только среди треков текущего исполнителя**.
- **Album**: Перемешивание происходит **только среди треков текущего альбома**.
- **All**: Перемешивание происходит **по всей библиотеке**

Его текущее состояние также отображается в правом нижнем углу (рядом с S, R, C). Если у вас включен shuffle, но включен режим, который ограничивает выборку, поведение клавиши `b` может показаться нелогичным, так как она будет выбирать следующий случайный трек только из ограниченного набора.

Попробуйте выключить перемешивание клавишей `s` — скорее всего, это решит вашу проблему. Если же вы хотите оставить случайный порядок, но сделать его более предсказуемым, попробуйте переключать режим AAA клавишей `m`, чтобы понять, как он влияет на воспроизведение.
