Самый надежный способ увидеть все команды и их текущие привязки (включая ваш:и пользовательские) внутри самой программы — нажать :, чтобы открыть поисковое командное меню

📌 Навигация по документу

    gg — переход к первой странице документа. Если ввести число перед командой (например, 42gg), произойдет переход на указанную страницу

    G (Shift+g) — переход к последней странице документа

    Пробел / Shift + Пробел — прокрутка экрана вниз / вверх (screen_down / screen_up)
    Ctrl + PageDown / Ctrl + PageUp — переход на следующую / предыдущую страницу (next_page / previous_page)

    Стрелки (↑, ↓, ←, →) — плавное перемещение экрана вверх, вниз, влево, вправо (move_up, move_down, move_left, move_right)

    ^ (Shift+6) — переход к левой стороне страницы с игнорированием белых полей (goto_left_smart)

    $ (Shift+4) — переход к правой стороне страницы с игнорированием белых полей (goto_right_smart)

    zz — переход к верхнему правому углу страницы (удобно для двухколоночных научных статей)

    gc / gC — переход к следующей / предыдущей главе (разделу) документа (next_chapter / prev_chapter)

    t — открыть поисковое оглавление документа (goto_toc)

    Home — открыть меню для ручного ввода номера страницы (goto_page_with_page_number)

🔍 Поиск

    / или Ctrl + f — открыть строку поиска по документу (search)

    n / N (Shift+n) — переход к следующему / предыдущему результату поиска (next_item / previous_item)

    c или c/ — поиск только в пределах текущей главы (chapter_search)

📏 Масштабирование и отображение

    + (или Shift + =) — увеличить масштаб (zoom_in)

    - — уменьшить масштаб (zoom_out)

    F9 — вписать страницу по ширине окна (fit_to_page_width)

    F10 — вписать страницу по ширине окна, игнорируя белые поля (fit_to_page_width_smart)

    F8 — переключение темного режима (инверсия цветов) (toggle_dark_mode)

    F5 — переключение режима презентации (страница вписывается в экран, клавиши перемещают по целым страницам) (toggle_presentation_mode)

    r / R (Shift+r) — поворот документа по часовой / против часовой стрелки (rotate_clockwise / rotate_counterclockwise)

📍 Метки (Marks), Закладки (Bookmarks) и Выделения (Highlights)

    m + буква (например, ma) — установить метку в текущем месте с именем буквы (set_mark)

    ` (обратный апостроф, клавиша с ~) + буква (например, `a) — мгновенный переход к установленной метке (goto_mark)

    b — добавить текстовую закладку в текущем месте (add_bookmark)

    db — удалить закладку (delete_bookmark)

    gb — открыть список закладок текущего документа (goto_bookmark)

    gB — открыть список закладок всех документов (goto_bookmark_g)

    h + буква (например, ha) — создать выделение выбранного типа/цвета для предварительно выделенного мышью текста (add_highlight)

    dh — удалить выделение (delete_highlight)

    gh / gH — перейти к списку выделений текущего документа / всех документов (goto_highlight / goto_highlight_g)

    gnh / gNh — переход к следующему / предыдущему выделению в текущем документе

    k / j — перемещение визуальной метки вверх / вниз (работает, если визуальная метка уже установлена) (move_visual_mark_up / move_visual_mark_down)

🌀 Порталы (Portals)
Уникальная функция Sioyek для связи двух удаленных частей документа (например, текста и фигуры).

    p — начать создание портала (фиксирует текущее место как источник). Затем перейдите к целевому месту и снова нажмите p, чтобы завершить портал (portal)

    gp — перейти к источнику ближайшего портала (goto_portal)

    dp — удалить портал, ближайший к текущему местоположению (delete_portal)

    P (Shift+p) или > — редактировать портал (edit_portal)

📂 Работа с файлами и окнами

    o — открыть диалог выбора файла (open_document)

    O (Shift+o) — открыть поисковый список недавно открытых файлов (open_prev_doc)

    Ctrl + o — открыть встроенный файловый менеджер (open_document_embedded)

    Ctrl + Shift + o — открыть встроенный файловый менеджер, начиная с папки текущего документа

    Ctrl + t — открыть новый экземпляр окна Sioyek

    q — закрыть текущее окно / выйти из программы (quit)

⚙️ Прочие полезные команды

    : — открыть командное меню с полным поисковым списком всех доступных команд и их текущих привязок клавиш (command)

    ,
    sioyek.info
    f — режим открытия ссылок в PDF с помощью клавиатуры (появляются номера рядом со ссылками) (open_link)

    v — режим выделения текста с помощью клавиатуры (keyboard_select)

    F (Shift+f) — умный переход (smart jump) с помощью клавиатуры (keyboard_smart_jump)

    Ctrl + c — копировать выделенный текст в буфер обмена (copy)

    Backspace / Shift + Backspace (или Ctrl + ← / Ctrl + →) — навигация по истории просмотров назад / вперед, работает даже между разными документами (prev_state / next_state)

⚠️ Важное примечание о конфигурации
Все стандартные привязки хранятся в файле keys.config. Вы можете открыть его прямо из программы для просмотра или редактирования:

    Нажмите : для открытия командной строки.
    Введите keys и нажмите Enter, чтобы открыть файл стандартных настроек

    Введите keys_user, чтобы открыть или создать ваш персональный файл переопределения клавиш (keys_user.config), который имеет приоритет над стандартным

Синтаксис конфигурации прост: команда клавиша (например, zoom_in +). Строки, начинающиеся с #, являются комментариями

В Sioyek мышь активно интегрирована в рабочий процесс, особенно для навигации по научным статьям и учебникам. Ниже приведен полный и точный перечень действий мыши по умолчанию, основанный исключительно на официальной документации и конфигурационных файлах keys.config / prefs.config

🖱️ Колесико мыши (Mouse Wheel)

    Прокрутка: обычное вращение колесика прокручивает документ вверх или вниз
    Ctrl + Колесико: масштабирование (zoom in / zoom out)
    В режиме Visual Scroll (включается клавишей F7 или командой toggle_visual_scroll): колесико мыши перемещает "визуальную линейку" (visual mark) по строкам текста вместо прокрутки самого документа
    В окнах предпросмотра (Overview) и помощника (Helper window): колесико используется для панорамирования или навигации по содержимому этих окон

🖱️ Средняя кнопка мыши (Middle Click / Нажатие на колесико)

    Умный переход (Smart Jump): средний клик по названию рисунка, уравнения, таблицы или библиографической ссылки мгновенно переносит к этому элементу (или открывает его предпросмотр), даже если в PDF нет активных гиперссылок
    Внешний поиск: средний клик по выделенному тексту (или названию статьи) выполняет поиск через внешний поисковик. По умолчанию используется Google Scholar (настраивается параметром middle_click_search_engine в prefs.config)
    Создание порталов: если нажать клавишу p, а затем сделать средний клик по элементу, Sioyek автоматически использует Smart Jump для создания портала к этому элементу
    Быстрое выделение: если в prefs.config включена настройка highlight_middle_click 1, средний клик по выделенному тексту сразу создает цветовое выделение (highlight)

🖱️ Правая кнопка мыши (Right Click)

    Визуальная метка (Visual Mark): правый клик по любой строке текста подсвечивает её. Это помогает не терять место при чтении. Быстрый возврат к последней визуальной метке осуществляется нажатием клавиши ` (обратный апостроф)
    Предпросмотр (Overview): правый клик по ссылке, названию рисунка или уравнения открывает всплывающее окно предпросмотра этого элемента без полного перехода к нему, что позволяет быстро ознакомиться с содержимым и вернуться обратно
    Synctex: если включен режим Synctex (клавиша F4), правый клик по тексту в PDF открывает соответствующий .tex файл в вашем редакторе кода ровно на нужной строке

🖱️ Левая кнопка мыши (Left Click)

    Выделение текста: стандартное выделение для последующего копирования (Ctrl + C) или создания цветового выделения (после выделения нажмите h + буква)
    lee-phillips.org
    Удаление выделения: левый клик по существующему цветовому выделению делает его активным, после чего его можно удалить командой dh
    lee-phillips.org
    Перетаскивание (Drag): по умолчанию выделяет текст. Если включить режим toggle_mouse_drag_mode, зажатие левой кнопки и перетаскивание будет панорамировать (сдвигать) документ, как в обычных просмотрщиках, вместо выделения текста
    github.com

⚙️ Настраиваемые действия с модификаторами
В файле prefs.config можно назначить любые команды Sioyek на клики с зажатыми клавишами-модификаторами. По умолчанию эти строки закомментированы, но их можно активировать

    shift_click_command
    control_click_command
    alt_click_command
    shift_right_click_command
    control_right_click_command
    alt_right_click_command

🔙 Дополнительные (боковые) кнопки мыши

    Если ваша мышь имеет боковые кнопки "Назад" / "Вперед" и операционная система передает их как стандартные события, Sioyek использует их для навигации по истории просмотров (аналогично клавишам Backspace / Shift + Backspace)

💡 Совет: Все действия мыши тесно связаны с клавиатурными командами. Чтобы увидеть, как мышь взаимодействует с текущими настройками, или переназначить поведение, откройте командное меню клавишей :, введите prefs или keys и изучите соответствующие конфигурационные файлы
